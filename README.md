# Easy GitHub upload

GitHub's browser uploader does not always accept folders. This package moves the compiled app code out of the `assets` folder, so every file can be uploaded directly to the repository root.

Upload all files in this folder to the root of your GitHub `ironlog` repository. The essential new files are `index.html`, `app.bundle.js`, and `sw.js`; replace the existing versions of those files when prompted. Then commit and open the GitHub Pages URL.
